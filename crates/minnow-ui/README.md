# minnow-ui

GPUI presentation.

- `features/`: capture overlay, pinned images, scroll capture and preferences.
- `flows/`: output attempts, result delivery and feature handoff.
- `presentation/`: shared appearance, layout, resources and feedback.
- `windowing/`: window options, dragging and native window effects.
- `navigation.rs`: feature transitions.
- `host.rs`: integration contract supplied by the executable.

`resources/` contains icons and translations. Business operations run through application services.
